Arquitectura del MVP (Hito 2)

Ecosistema Agnóstico Desacoplado

El frontend web consume servicios REST mediante fetch(). Cuando el servidor local FastAPI + PostgreSQL (INCI) está activo, sirve el catálogo indexado por el scraper; en despliegue estático (GitHub Pages), conmuta automáticamente a APIs públicas en vivo sin datos estáticos inventados.

1. Captura y Visión

HTML5 Canvas / OpenCV. Evaluación de luminancia, eritema (acné) y contraste nasal (puntos negros) en RAM.

2. Motor INCI

Mapeo imparcial entre condición cutánea y principios activos (Ácido Salicílico, Niacinamida, Ceramidas).

3. Integración API

Prioridad: FastAPI → Serper Shopping (opcional) → API Mercado Libre Chile (MLC) → Open Beauty Facts.

4. Enlaces Retail Chile

Redirección directa sin sesgo comercial hacia Cruz Verde, Salcobrand, Dr. Simi, Ahumada, Preunic y Maicao.
